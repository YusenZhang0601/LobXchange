# 待执行计划 (Pending Plans)

本文件夹用于存放项目在下一个微小迭代中拟执行的改进计划与设计文档。

## 工作流规范

1. **制定计划**：在进行任何代码修改或功能演进前，先在本目录下新建一份微小计划文档（例如：`PLAN_001_build_and_benchmark.md`）。
2. **确认边界**：严格控制改动范围，遵循“小步快跑、敬畏技术、不动大底盘”的原则。
3. **执行与验证**：按照计划逐项实施，并运行单元测试与对账验证。
4. **归档转移**：改动验证 100% 正确且无副作用后，将该计划文件从本目录移动至 `../archived_plans/` 目录中归档。
