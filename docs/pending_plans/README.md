## 状态定义

- **提案**：只有想法或设计，尚未实现。
- **分支已实现**：代码存在于个人分支，但不代表作者仓库已接纳。
- **上游已合入**：作者仓库已经包含该改动。
- **重新验证通过**：基于作者最新代码 fresh build，并完成与风险相称的测试。

计划只有同时达到“上游已合入”和“重新验证通过”，才从这里移入 `../archived_plans/`。历史日志里的单次通过结果不能替代当前验证。
