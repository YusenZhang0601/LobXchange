# 模拟交易所项目开发日志 (Development Logs)

本目录用于记录 `LobXChange` 项目的日常开发、研究复盘、技术债分析以及架构演进等重要信息。

## 日志记录规范

1. **按日归档**：日志文件以当天的系统日期命名，格式为 `YYYY-MM-DD.md`（例如：`2026-07-20.md`）。
2. **每日一记**：每天只对应一个日志文件。
   - 记录前务必读取系统当前时间。
   - 如果当天的日志文件不存在，则新建该文件。
   - 如果当天的日志文件已存在，则在文件末尾追加（Append）新内容，并使用时间戳（如 `## [HH:MM:SS] 更新主题`）进行分割。
3. **内容要求**：
   - 确保所记录的发现、分析和设计决策都是基于对真实代码的复盘和验证。
   - 保持小步快走、敬畏技术的工程精神。
